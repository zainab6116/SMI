# SMI Website
Edit contact details ONLY in `js/config.js` (phone, WhatsApp, hours, map embed, directions link, social links).
Run locally: `python3 -m http.server` then open http://localhost:8000
Publish: push to GitHub > Settings > Pages > Deploy from branch `main` / root.
Logos are in `images/` (SVG). Pages: index, about, programs, contact.
